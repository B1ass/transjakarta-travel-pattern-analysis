# TransJakarta Travel Pattern Analysis

A data analytics project focused on exploring TransJakarta passenger travel patterns, identifying peak travel hours, analyzing popular corridors and stops, and understanding journey duration using Python and Looker Studio.

## 📌 Project Overview

This project was developed as part of the Comprehensive Data Analytics Program at Hacktiv8 to practice data analysis, data exploration, and interactive dashboard development.

The project analyzes TransJakarta passenger transaction data from April 2023. The dataset was explored and processed to identify passenger travel patterns, including daily travel trends, hourly distributions, frequently used corridors, departure and destination stops, and travel duration.

The analysis results are presented through an interactive dashboard built using Looker Studio to make the findings easier to explore and understand.

## 🎯 Objectives

- Explore and analyze TransJakarta passenger transaction data.
- Identify daily passenger travel trends.
- Analyze passenger distribution across different hours.
- Identify the busiest TransJakarta corridors.
- Determine the most frequently used departure and destination stops.
- Explore the relationship between the number of stops and travel duration.
- Build an interactive dashboard to communicate analytical findings.

## 🔄 Project Workflow

### 1. Data Understanding & Exploration
Explore the TransJakarta passenger transaction dataset to understand its structure, attributes, and overall data characteristics.

### 2. Data Preprocessing
Prepare the dataset for analysis by handling data types, processing date and time attributes, and preparing relevant analytical fields.

### 3. Exploratory Data Analysis (EDA)
Analyze passenger travel patterns through daily trends, hourly distributions, popular corridors, departure and destination stops, and journey duration.

### 4. Dashboard Development
Develop an interactive Looker Studio dashboard to present the analytical results through visualizations and key performance indicators.

### 5. Insights & Interpretation
Interpret the visualizations to understand passenger travel behavior and identify patterns in TransJakarta transportation usage.

## 📊 Dataset

The dataset contains TransJakarta passenger transaction records for **April 2023**.

The analysis includes attributes related to:

- Transaction information
- Corridor identification and names
- Departure and destination stops
- Tap-in and tap-out timestamps
- Passenger travel duration
- Number of stops traveled
- Travel date, hour, and time category

The dataset contains **189,500 analyzed passenger transactions**.

## 📈 Dashboard

The interactive dashboard consists of two pages:

### 1. Travel Overview

Provides an overview of passenger travel patterns, including:

- Total Trips
- Average Travel Duration
- Daily Travel Trend
- Hourly Travel Distribution
- Top 10 Busiest Corridors

### 2. Stops & Travel Duration Analysis

Focuses on passenger stop preferences and journey characteristics, including:

- Top 10 Departure Stops
- Top 10 Destination Stops
- Travel Duration Distribution
- Stops vs Travel Duration
